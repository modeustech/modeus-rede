Partner logo assets (web-ready)

Files included:
- *_1x.png  : 320x160 transparent PNG (use as-is)
- *_2x.png  : 640x320 transparent PNG (retina)
- *_1x.webp : lossless WebP (smaller, modern browsers)
- *_2x.webp : lossless WebP (retina)

Design notes:
- All logos were cleaned (white background removed), tightly cropped, and placed on a consistent canvas so they align nicely in a row/grid.
- 'loods-5' and 'wehkamp' were optically scaled slightly so none of the logos feel oversized next to the others.

Suggested HTML:
<img src="flexaro_1x.png" srcset="flexaro_1x.png 1x, flexaro_2x.png 2x" width="320" height="160" alt="Flexaro">

If you prefer a smaller on-page size (recommended), set width/height in CSS (e.g. height: 48px; width: auto;).
